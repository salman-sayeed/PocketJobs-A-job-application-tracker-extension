# PocketJobs 


PocketJobs is a lightweight browser extension that helps job seekers track job applications without leaving their browser. Instead of maintaining spreadsheets or notes, PocketJobs lets users save job postings directly from the current tab, organize applications and review them later from a simple interface.

## 💠 Features
* Save the current job posting URL automatically
* Add the position title before saving
* Track all saved applications in one place
* Search and filter applications
* Prevent duplicate job entries
* View application history with dates
* Open saved job postings directly from the extension

## 💠 Tech Stack
```bash
JavaScript, HTML, Tailwind CSS, Chrome Extension APIs, Chrome Storage API, Node.js
```

## 💠 Installation

1. Clone this repository.
2. Run:

```bash
npm install
```

3. Build Tailwind CSS.
4. Open Chrome Extensions.
5. Enable Developer Mode.
6. Click "Load Unpacked".
7. Select the project folder.
